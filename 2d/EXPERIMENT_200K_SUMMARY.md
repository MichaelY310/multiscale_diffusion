# ImageNet-256 实验：模型大小与 FID@200K

最后核对：2026-09-05。

## 统一口径

- 只把原生 ImageNet ILSVRC 训练的结果计入合法 FID；旧 Hugging Face 预处理数据不进入本表。
- `FID@200K` 指训练到 200,000 个 optimizer updates 的 checkpoint。
- FID 协议为 50,000 个样本、ADM ImageNet-256 reference、CFG=1.0。
- RDD diffusion 使用 DDPM、noise filling；普通 DiT 没有跨 stage 的 noise filling。
- 训练分配按细到粗写：`[32,16,8]`。
- 采样步数按真实生成顺序粗到细写：`[8,16,32]`。
- `M` 表示百万参数；Multistage 参数量是三个独立模型之和，Unified 是一个共享模型的唯一参数量。

## 不应混入该表的实验

- 旧 Hugging Face 预处理数据训练的 RDD/DiT：FID 绝对值无效，只能提供趋势启发。
- DMD 三步探索：没有合法的 50K-sample FID@200K，而且 distillation update 不能直接等同普通 diffusion 的 optimizer update。
- Video 和 3D：不使用 ImageNet FID@200K 这一评价口径。
- FM CFG=1.5 的 400K FID=3.358714 很强，但不能填入 CFG=1.0 的 200K 收敛比较。

## 200K 的直接结论

在同一 DDPM250、CFG1.0、50K-sample 口径下：

1. Unified-XL 300/300/400 最好：FID 10.664；
2. Unified-L 300/300/400 次之：FID 12.840，但参数少 32.2%；
3. 两阶段 16→32 的 500/500 为 16.194；
4. Unified-L 100/300/600 为 18.119；
5. Unified-L 600/300/100 为 22.869；
6. 原始 DiT-XL/2 为 29.662。

所以当前关于训练分配最可靠的结论仍然是：在已完成的三阶段 Unified-L 对照中，300/300/400 明显优于两个极端分配；新 8→32 与 400/300/300 必须等到 200K 并使用相同评估协议后才能加入数值排序。
